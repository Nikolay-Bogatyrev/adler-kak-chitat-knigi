# Книжный клуб: Адлер, «Как читать книги»

- `public/slides.html` — слайды для показа в Google Meet: презентация, квизы, тренинг по 15 правилам. Ответы группы вписывает ведущий.
- `public/index.html` — «Спутник»: метод, практика, тренинг, подбор полки. Участник может пройти тренинг сам.

Сервера нет. Всё, что вписано, хранится в браузере (localStorage) того, кто вписывал, и не синхронизируется.
В конце занятия на последнем слайде скачайте итоги в `.md`, а участники скачивают свой конспект в «Спутнике».

## Как открыть

Двойной клик по файлу: обе страницы работают без интернета. Шрифты слайдов встроены, «Спутник» берёт шрифты с Google Fonts и без сети покажет запасные.

## Если нужна ссылка для чата

Папку `public/` можно выложить как статичный сайт, например `vercel deploy --prod` из этой папки после `vercel login`.
Тогда «Спутник» — это корень сайта (`/#training`), слайды — `/slides.html`. Слайд «Как мы работаем» сам покажет ссылку на «Спутник».
